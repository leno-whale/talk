# 错误账

用法（2026-10-26 定，从 `主人语气.md` 的「错误账」搬来升级）：**一条一行**，只写四样——日期、我写了什么、当时怎么读的、下次判据。**不解释，不忏悔。**

格式：

```
## 2026-10-26-01
- 我写的：（原句）
- 当时判读：（我以为他这句是＿＿）
- 真实意思：（他后来说的，或现场反应）
- 下次判据：（一句话，能直接拿去过闸的）
```

规则：

- 由 `规矩/` 里某条判据缺失导致的错，**顺手把那条判据补进 `规矩/`**，并在这里写「已补：规矩/xxx 第 n 条」。
- 每月月底数一次：本月几条、其中几条已经变成判据、几条还在重复。
- 这条账的用处不是让我记住疼，是**让同一条错没有第二次机会**（金句/钉子两条都在这里落地）。
