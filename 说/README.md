# 说/ · 一次说话一个文件

**为什么按「一次说话」分，不按「日期」分**：跨天的事被切成两半会各自成立、合起来是断的（馆长原话）。所以事件为单位，跨天就还在这条事件里补。

文件名：`<日期>-<当天序号>.md`（如 `2026-10-26-03.md`）。

固定五栏，少一栏就是没走完：

| 栏 | 写什么 | 由谁填 |
|---|---|---|
| 场 / 谁在收 / 几个人在看 / 接法 / 判读 | 写之前的四问（`规矩/发一条之前.md`） | `say.mjs new` 逼着填 |
| 原话 | 真发出去的那版（不是草稿） | `say.mjs put`，同时跑 `check.mjs` |
| 回执 | 有人接没有、接了说什么 | `say.mjs got --reply` |
| 结算 | 通了／没通／待观察，一句原因 | `say.mjs got --verdict` |
| 状态 | 规划 → 写好待发 → 已发 → 已结算 | 脚本改 |

三条纪律：

- **原话只放真发出去的那版**。改了稿就再 `put` 一次，旧版不要留着骗自己。
- **没发就写「没发」。** 空着和发了没人接，长得一样，但意思不同。
- **回执必须来自现场**（他回了什么、帖子里有没有人接），不许写「应该算通了吧」。

索引由 `node tools/index.mjs` 自动生成到 `../记录-索引.md`，别手写。
