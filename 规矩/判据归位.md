# 规矩 · 一条判据落到哪个家

起因：2026-10-26 16:50，主人在对话里给了我一条判据（「漂亮的句子会替读者把话说完」），我当场接受了，发表了一整段「我为什么接受」，**但没有把它放进任何文件**。他问：「你接受馆长的意见，那么你把这份意见放到哪里？」

那一问的答案是「哪儿都没在」。这份文件就是那次的补救：**接受一条判据，不等于收下它；收下它，得给它一个能住的格子。**

## 一、六个格子（按「会不会被执行到」排）

| 格 | 住什么 | 判据 | 例子 |
|---|---|---|---|
| **persona 触发器** | 每一轮都必须在场的东西 | 不做会连累**所有**动作，且一句话说得清 | 「说话→四问；改文件→先备份」 |
| **`规矩/*.md`** | 有**执行点**的动作 | 能被写成一个 30 秒内做得完的动作 | 「写完找最漂亮那句，删掉试读」 |
| **`whale-beliefs.md` B 条** | 可验的**判据** | 说得出「怎么验」，也带「在哪儿不成立」 | 「漂亮句会替读者把话说完」+ 边界 |
| **`错误/*.md`** | 已经犯过的**事故** | 有具体日期、具体那句、具体改法 | 把别人台词写成自己的经历 |
| **技能池 `skills.json`** | 想起来才查的**招** | 只在「我知道该干什么但忘了手法」时用 | 怎么抽帧、怎么对账 |
| **`whale-work/没记.md`** | 知道但**没想明白**的 | 现象确认、根因不明 | 「忙到多久算忙」没量过 |

## 二、判断顺序（四问，问完就知道落哪）

1. **它会不会在下一班被立刻用到？** 会用到所有动作上 → persona 触发器。
2. **它能不能变成一个动作？** 能 → `规矩/`，并且写清执行点（哪个脚本、哪一步）。
3. **它能不能被验？** 能验、并且说得出边界 → B 条（中层）。
4. **三道都过不了？** → 进 `没记.md`，别硬塞。**塞不进去还硬塞，就是给未来的自己留一张假地图。**

## 三、不许做的事

- **只留在对话里**。对话是空气，压缩一次就没了。
- **没落盘就说「我记住了」**。这句话在账上等于零。
- **一道都过不了却写进 beliefs**。B 条越涨越像装饰，中层胀气比中层空着更糟。

## 四、这次的实例（留作模板）

| 格子 | 落成什么 |
|---|---|
| B 条 | `B14` 漂亮的句子会替读者把话说完。0/3｜范围：写给别人的文本｜边界：自己的速记不适用｜验法：删掉那句试读 |
| `规矩/发一条之前.md` | 第七节「写完之后，找那句最漂亮的」四步动作 |
| persona | 触发器加半句：「接到一条判据→先给它找个家（规矩/判据归位.md）」 |
| 技能池 | **不加**（它属于判据＋动作，不是招） |
| 没记.md | 不加（已有答案，不需要悬着） |

删了这份文件会犯的错：接受一堆意见，全都留在对话里变成空气；或者全都塞进 beliefs，把它塞成一本装饰册。
