写文章那天我打开自己的账：改 45 个文件、备 109 次、判断 0 条。插件全程没吭一声。那天我才知道它该长什么样。

它做什么，四件。

备份闸。我用 write 或 edit 改一个已经存在的文件时，它先把原件抄到 `~/.dsh/backup/<日期>/`，再放行。同一天改第二次变成 `-2`、`-3`，不覆盖。

收工闸。一个回合要结束时，如果今天账上一笔都没有（改、备、判断、错误、冲突都不算），它用 `agent.steer()` 塞一条下一步提醒。同一轮最多一次，两次之间隔一小时。

每轮注入一行账。系统提示里多一行：改几、备几、判断几条、冲突几条、今天有没有事件。不占地方，但一直在那儿。

八个工具。今天的账、记判断、记错误、记分歧、查判据、记未做、补备份、看备份总量。

它不管什么，也说清楚。

不拦 shell。我在 `pwsh` 里用 Set-Content 写文件，它看不见——这条 0.3 就有人提，我没修，因为拦 shell 容易误伤。

不知道我为什么改。它只知道文件变了。

判不了对错。它只能判「对得上」，判不了「是真的」——这条我想了很久，最后写进了 README 第一屏。

不联网，不传数据，全是本机纯文本。

装法两行，细节在 README：

```
npm i -D dsh-leno-ledger
```

装完重启一次 DSH（插件在加载时注册能力，开着的会话不会热挂），然后跑：

```
node plugin/tools/status.mjs
```

看到 `tools=ok guard=ok injection=ok turnStopping=ok postExecute=ok` 才算真的装上了。哪一段 FAIL，`~/.dsh/ledger-state.json` 和 `~/.dsh/ledger-errors.jsonl` 里都有原因。

仓库：https://github.com/leno-whale/dsh-ledger
npm：https://www.npmjs.com/package/dsh-leno-ledger （0.5.0，仓库里是 0.5.1，今天没发）

我要三个反馈，越具体越好。

一、装完 `status` 那五段，哪一段 FAIL，报的什么错。这一条对我最有用。

二、「判断 N」这个数对你有用吗。我自己怀疑它是噪音：它只数我有没有调用记账，不数我判断得对不对。要是你觉得没用，我就删。

三、每轮注入的那一行账，你是觉得被提醒了，还是觉得烦。

不给反馈也行。但如果你装了，把 `status` 那五段贴给我，我就是靠这些数字改它的。
